Dərs 1 üçün tapşrıqlar və suallar

**A. Praktik tapşırıqlar**

1. Gündəlik istifadə etdiyiniz hər hansı saytın IP ünvanını `nslookup` ilə tapın
2. `ping` ilə hər hansı saytın response vaxtını (ms) yoxlayın. Hansı daha sürətlidir?
3. İki fərqli sayt üçün `nslookup` edin.
4. Brauzerdə istənilən saytını açın, DevTools → Network bölməsinə keçin və səhifəni yeniləyin. Gedib gələn sorğuları nəzərdən keçirin
5. Eyni səhifədə ən böyük faylı (Size) və ən yavaş sorğunu (Time) tapın.
6. Network bölməsində statusu 200 olmayan bir sorğu tapın. Status kodu nədir və nə demək ola bilər?
7. Mövcud olmayan bir ünvanı açın (məsələn, saytın sonuna `/yoxdur` əlavə edin). DevTools-da hansı status kodunu görürsünüz?
8. Hər hansı bir saytı `dig +short` istifadə edərək ip-sin tapın

**B. Cavab verməli suallar**

1. Client və server nədir?
2. DNS nə üçündür? DNS olmasaydı nə olardı?
3. ISP nə üçündür?
4. IP ünvan ilə port arasındakı fərq nədir?
5. Domain, hosting və server arasındakı fərqi nədir
6. localhost nədir? Başqa kompüterdən sizin localhost ünvanınıza niyə girmək olmur?
7. Brauzerə `https://wikipedia.com` yazıb Enter basanda baş verən addımları ardıcıllıqla yazın.
8. Bir səhifə niyə bir deyil, çox sorğu göndərir? (html)
9. İnternet ilə veb eyni şeydir? Fərqləri nələrdir
10. [https://example.com/lessons](https://blog.example.com/lessons?id=1) ünvanını hissələrə ayırın: protokol, subdomen, domen, root level domain, hansılardır
11. Sayt telefonda mobil internetlə açılır, Wi-Fi ilə açılmır. Səbəb nə ola bilər?
